# Expense Tracker (Console Java)

A console-based expense tracker built with Core Java.

## Features
- Add expense
- Delete expense
- List expenses
- Filter by category
- Calculate total
- File persistence
- Sorting by date and amount

## Tech Stack
- Java 17+
- OOP
- Collections
- File I/O
- Exception Handling

## Architecture
- model → domain objects
- service → business logic
- repository → file persistence
- ui (Main) → console interface

## How to Run
1. Clone repo
2. Run Main.java
3. Use console menu
